## About Me

I am an applied machine learning and AI engineer based in Dresden, Germany. I hold a German Diplom in Business Informatics (M.Sc. equivalent) from TU Dresden and have hands-on experience in industrial signal processing, production ML services, data-driven optimization, and local-first AI applications.

I work at the intersection of machine learning and software engineering—turning noisy data, domain constraints, and research prototypes into testable systems that people can use.

- 🏭 **Industrial ML:** time-series classification, anomaly detection, semantic segmentation, and HFCT signal analysis
- 🧠 **Applied AI:** cited RAG, structured LLM workflows, semantic knowledge graphs, and human-in-the-loop systems
- ⚙️ **Optimization:** multi-objective search, reinforcement learning, dynamic programming, and profit-aware decision pipelines
- 🛠️ **Engineering:** Python and TypeScript systems spanning desktop tools, APIs, web applications, plugins, tests, and CI

## Selected Highlights

- Built a memory-efficient desktop workflow for engineers to inspect and label paired industrial sensor recordings containing up to **560 million samples** without loading entire files into memory.
- Developed classification and segmentation workflows for partial-discharge signal analysis, including a deployed inference path for customer measurements.
- Built data-driven structural design software connecting predictive models, OpenSees analysis, and evolutionary optimization with interactive Pareto exploration.
- Led a three-person energy-storage optimization team to **350th place among 6,000+ entries (top 6%)** using leakage-aware validation and profit-based model selection.
- Released **Vault Coach**, an open-source Obsidian learning assistant built around source-grounded answers, practice, mastery tracking, and reviewable AI suggestions.

`Python` `pandas` `scikit-learn` `XGBoost` `Time-Series Validation` `Feature Engineering` `Decision Optimization`
